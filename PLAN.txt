================================================================
  NGƯỜI 1 — BTL 1 (Cú pháp)
================================================================
Công việc:
  [x] 1.1 Tách mệnh đề (đã hoàn thành)
          File: extract.py
          Output: input/raw_contracts.txt, output/clauses.txt

  [ ] 1.2 Phân cụm danh từ (IOB tagging)
          - Dùng underthesea hoặc pyvi để POS tag
          - Gắn nhãn B-NP / I-NP / O cho từng token
          Output: output/chunks.txt
          Định dạng mỗi dòng: <token> <nhãn IOB>
          Ví dụ:
              Bên     B-NP
              B       I-NP
              sẽ      O
              thanh   O
              toán    O

  [ ] 1.3 Phân tích phụ thuộc
          - Dùng underthesea dependency parsing
          - Mỗi token có: token, head, quan hệ phụ thuộc
          Output: output/dependency.json
          Định dạng JSON:
          [
            {
              "clause": "Bên B sẽ thanh toán toàn bộ tiền thuê.",
              "tokens": [
                {"id": 1, "token": "thanh toán", "head": 0, "dep": "root"},
                {"id": 2, "token": "Bên B",      "head": 1, "dep": "nsubj"},
                {"id": 3, "token": "tiền thuê",  "head": 1, "dep": "obj"}
              ]
            }
          ]

Ghi chú: clauses.txt đã sẵn sàng, bắt đầu ngay được.


================================================================
  NGƯỜI 2 — Gán nhãn (dòng 1-360) + BTL 2.1 NER
================================================================
Công việc:
  [ ] GÁN NHÃN — dòng 1 đến 360 trong output/clauses.txt
          Gán đồng thời 2 loại nhãn trên cùng 1 câu:

          Nhãn NER (cho tác vụ 2.1):
              PARTY    — Bên A, Bên B, Người lao động, Công ty...
              MONEY    — 10.000.000 VNĐ, 50%...
              DATE     — ngày 05/5/2024, trước ngày 5 hàng tháng...
              RATE     — lãi suất, mức thuế, tỷ lệ...
              PENALTY  — mức phạt, bồi thường...
              LAW      — Điều 19, Nghị định 93/2017/NĐ-CP...

          Nhãn Intent (cho tác vụ 2.3):
              Obligation          — bắt buộc phải làm
              Prohibition         — không được làm
              Right               — có quyền làm
              Termination         — điều kiện chấm dứt

          Format file gán nhãn (labeled_2_NER.jsonl):
          {"text": "Bên B phải trả 10.000.000 VNĐ trước ngày 05/5/2024.",
           "entities": [
             {"text": "Bên B",           "label": "PARTY"},
             {"text": "10.000.000 VNĐ",  "label": "MONEY"},
             {"text": "ngày 05/5/2024",  "label": "DATE"}
           ],
           "intent": "Obligation"}

  [ ] 2.1 Huấn luyện mô hình NER
          - Dùng toàn bộ data gán nhãn (labeled_2_NER.jsonl + labeled_3_NER.jsonl)
          - Có thể dùng: spaCy, transformers (PhoBERT), hoặc CRF
          Output: output/ner_results.json

Ghi chú: Bắt đầu gán nhãn ngay, không cần chờ Người 1 xong.


================================================================
  NGƯỜI 3 — Gán nhãn (dòng 361-721) + BTL 2.2, 2.3
================================================================
Công việc:
  [ ] GÁN NHÃN — dòng 361 đến 721 trong output/clauses.txt
          Cùng format với Người 2 (labeled_3_NER.jsonl)
          Sau khi xong ghép lại: cat labeled_2_NER.jsonl labeled_3_NER.jsonl > labeled_all.jsonl

  [ ] 2.2 SRL — Gắn nhãn vai trò ngữ nghĩa
          - Dùng data từ 2.1 (ner_results.json) + clauses.txt
          - Xác định vị ngữ chính và các vai trò: Agent, Predicate, Theme, Recipient, Time, Condition
          Output: output/srl_results.json
          Định dạng:
          [
            {
              "clause": "Bên A phải bàn giao vật tư cho bên B.",
              "predicate": "bàn giao",
              "roles": {
                "Agent":     "Bên A",
                "Theme":     "vật tư",
                "Recipient": "Bên B"
              }
            }
          ]

  [ ] 2.3 Phân loại ý định
          - Dùng labeled_all.jsonl (nhãn intent)
          - Baseline: TF-IDF + Logistic Regression
          - Nâng cao: PhoBERT fine-tune
          - So sánh kết quả 2 phương pháp
          Output: output/intent_classification.txt
          Định dạng mỗi dòng: <mệnh đề> ||| <nhãn>

  [ ] Viết báo cáo PDF (tổng hợp kết quả cả nhóm)

Ghi chú: Bắt đầu gán nhãn ngay song song với Người 2.
